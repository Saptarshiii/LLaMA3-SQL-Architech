# LLaMA3-SQL-Architech

This repository contains a small project that fine-tunes a Llama 3 base model on a text-to-SQL dataset and a lightweight Streamlit UI to generate SQL given a database schema and a natural-language question.

High-level contents
- `app.py` — Streamlit application to interact with the finetuned model locally
- `requirements.txt` — Python dependencies for running the app
- `llama3-sql-lora/` — directory containing the finetuned PEFT adapter (weights, config and tokenizer files)
- `Notebook/Model Finetuning.ipynb` — the training notebook used to finetune the adapter

Model
- Base model: `meta-llama/Llama-3.2-3B`
- Adapter / finetuned weights: folder `llama3-sql-lora` (PEFT format, `adapter_model.safetensors`)

Quick overview
1. Install dependencies and create a Python virtual environment.
2. Use the Streamlit app (`app.py`) to load the base model and attach the adapter folder to generate SQL.

Why this repo
- Provide a lightweight UI for evaluating text-to-SQL finetuning results.
- Keep finetuned weights separate via PEFT adapters so the base model is not re-saved.

Getting started (Windows PowerShell)

1) Create and activate a virtual environment and install requirements:

```powershell
python -m venv .venv; .\.venv\Scripts\Activate.ps1
pip install -U pip
pip install -r requirements.txt
```

2) Run the Streamlit app:

```powershell
streamlit run app.py
```

3) In the app UI (sidebar):
- Set `Base model` to `meta-llama/Llama-3.2-3B` (or local path).\
- Set `Adapter / finetuned folder` to `llama3-sql-lora` (the folder included in this repo).\
- Toggle `Load from local files only` if you do not want the app to fetch from the Hugging Face Hub.

Notes
- The adapter files include `adapter_model.safetensors` which is a large binary; when pushing to GitHub use Git LFS for large files (see `Pushing / Git LFS` below).
- For large models prefer running on a GPU with sufficient VRAM. The app uses `device_map='auto'` to distribute tensors when possible.
- If you need to authenticate to Hugging Face Hub, run `huggingface-cli login` or set `HF_TOKEN` environment variable.

Pushing to GitHub (large files)
- If you plan to push the adapter `safetensors` file to GitHub, install and enable Git LFS first:

```powershell
# install and enable git-lfs (one-time)
choco install git-lfs    # or download from https://git-lfs.github.com/ and run installer
git lfs install
# track safetensors
git lfs track "*.safetensors"
# commit the .gitattributes file generated by git-lfs
git add .gitattributes
git commit -m "track safetensors with git-lfs"
```
